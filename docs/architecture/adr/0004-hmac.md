# ADR-0004: HMAC instead of plain SHA-256

## Status

Accepted.

## Context

`computeHash` today is unkeyed SHA-256. Anyone who knows the field layout can compute a valid code from the database file alone.

## Decision

Replace the hash with HMAC-SHA-256. The key is `HMAC_SECRET` on the server, not in the database.

## Consequences

- Existing 23 tests must still pass. Tests receive the same key through the environment.
- Losing the key means new records cannot be verified against old ones. Back up the key.
- Skill: `hmac-swap`. Core agent only.
