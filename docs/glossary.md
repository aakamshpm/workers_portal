# Glossary

| Word | Meaning here |
|---|---|
| Offer | Formal terms a contractor sends. Status: PENDING, ACCEPTED, DECLINED, CANCELLED |
| Locked | After the worker accepts, those figures cannot be changed |
| Work period | A range of dates and a day count, not one row per day |
| Confirm state | WAITING, CONFIRMED, or DISPUTED on a work or payment row |
| Hash chain | Append-only codes over seven record types. Proves a row was not changed |
| HMAC | Keyed hash. Database file alone is not enough to forge a code |
| Textbee | Hosted SMS API. A spare Android phone sends and receives the SMS |
| Gateway phone | That spare Android. Must stay on and charged |
| PWA | The existing React app, installable from the browser. Not a native app |
| Opt-in | Worker or contractor chose to appear in nearby search |
| Place | Public map listing (business). Not a confirmed vacancy |
| Labour office | AUTHORITY role. Website only |
