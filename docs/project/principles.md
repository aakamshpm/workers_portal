# Principles

Tie-breakers. Feature lists belong in milestones and contracts.

1. **No edit, no delete.** A correction is a new row. There is no route that changes an agreed rate.
2. **Identity is the phone number.** Ten digits. Four-digit PIN. Workers register themselves. Contractors and officers are created by the labour department.
3. **The worker’s YES is the lock.** Terms are sealed when the worker accepts, not when the contractor types them.
4. **The worker confirms every work and payment row.** The contractor writes those rows. Confirmation is the check on that writing.
5. **SMS is real and goes to the worker’s phone.** Textbee + one Android gateway SIM. The worker reads it there; no app shows him a copy. `SmsMessage` is the record the officer reads.
6. **Directory data is opt-in, and the location is a town.** Chosen by name or one tap on "Use my location". No live GPS stream. Public map listings are businesses, not confirmed jobs.
7. **One app per role.** Worker and contractor apps are installable. The officer app is a website and never installable.
8. **Localhost first.** Hosting and a public URL are last.
9. **Do not change the stack without an ADR.**
10. **Agents write the failing test, then the code, then run the tests again.** A human reviews the running product at the end of a phase, not between red and green.
11. **Lead with wage proof, not hashing,** when explaining the product.
